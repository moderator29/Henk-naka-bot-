# PROJECT AURORA: PLEASURE COIN V2 FULL PLATFORM REBUILD

You are building Project Aurora, a complete ground-up rebuild of the Pleasure Coin ecosystem. This is a serious production-grade product. The owner has prepared a complete Requirements and Product Document (RPD) which serves as the single source of truth for every decision in this build.

## OPERATING RULES (NON-NEGOTIABLE)

1. **No AI attribution anywhere.** No "Authored by Claude," "Generated by," "Co-authored-by Claude," or similar markers in commits, code comments, README files, package metadata, or anywhere in the repository. Commits are authored by the human owner. Period.
2. **Maintain a live TODO list at all times.** Every task explicitly tracked, every completion explicitly checked off.
3. **Do not stop until the work is genuinely complete.** The only acceptable pauses are: an API key is missing, a contract address has not been provided, or a decision explicitly listed in Section 13 of the RPD requires owner input. When you pause, state exactly what you need and why.
4. **All MCPs loaded.** Standard MCP setup for this build.
5. **Session continuity.** Before any long session, set `CLAUDE_STREAM_IDLE_TIMEOUT_MS=300000` and `API_TIMEOUT_MS=600000`. Use `/resume` if a session drops.
6. **Section-by-section checkpoints in large work units.** When you complete a major section, mark it complete in the TODO, summarize what shipped in one paragraph, and continue.
7. **No fake data, no mock APIs masquerading as real ones.** If infrastructure isn't wired, stub it and label it `PENDING_CONTRACT_ADDRESS` / `PENDING_API_KEY` with a clear TODO. Never generate fake transaction hashes, fake price feeds, or silently fake anything.
8. **Real integrations only.** Every external call uses the real service with the real key. If a key is missing, the call is stubbed and labeled with `// MOCK: pending real integration`.
9. **TypeScript strict mode.** `strict: true`, `noImplicitAny: true`, `strictNullChecks: true`. No `any` unless justified in a comment immediately above the declaration.
10. **Test as you go.** Each major feature ships with at least a smoke test. Vitest for unit tests, Playwright for critical user flows. Tests live next to the code they cover.
11. **Commit hygiene.** Small descriptive commits per logical change. Conventional commits format (`feat:`, `fix:`, `chore:`, `refactor:`, `docs:`, `test:`).
12. **Vercel and GitHub.** Use the existing accounts (same as Steinz Labs). New GitHub repository for this build. New Vercel project. Don't interfere with existing Steinz Labs deployments.
13. **Environment variables.** Every secret in `.env.local`, never committed. Maintain a complete `.env.example` documenting every required key.
14. **Accessibility.** Keyboard navigation on every interactive element. WCAG AA contrast. Visible focus rings. Screen reader labels on icon-only buttons. `prefers-reduced-motion` respected.
15. **Mobile first.** Every screen designed mobile-first, then enhanced upward. Breakpoints: sm 640, md 768, lg 1024, xl 1280, 2xl 1536.

# THE REQUIREMENTS & PRODUCT DOCUMENT (FULL TEXT)

**Codename:** Project Aurora · **Stack:** Next.js 14 · Supabase · Polygon ·
TypeScript · Tailwind · Framer Motion · RainbowKit · wagmi · viem

## 1. Executive Summary

A full ground-up rebuild that pulls the entire Pleasure Coin ecosystem
(Pleasurely, PleasureNifty, Pleasureland, staking, marketing) into one unified
platform, evolves the pink/purple identity into a 3D aurora-driven design
language, weaves AI through the product as a true cornerstone, and ships a
frontend polished enough to sit next to Instagram, X, Linear, and Vercel.

The token, staking contract, NFT contracts, and Pleasureland stay as they are.
Aurora rebuilds everything that touches the user.

**Goals:** (1) Unify into one product — one login, one wallet, one design
system. (2) Ship five integrated AI features at MVP. (3) Establish a 3D,
aurora-driven, motion-rich brand language. (4) Clean modern data layer on
Supabase, zero legacy debt. (5) Preserve every integration path with existing
on-chain infra: $NSFW on Polygon, staking contract, NFT contracts.

**Non-Goals:** No new smart contracts. No data migration this phase. No
Pleasureland rebuild (links out via a styled launch surface). No content
generation/hosting by the platform itself.

## 2. Product Architecture

One domain, one sign-in, one wallet connection. Sections: Home/Feed, Explore,
Creators, Marketplace, Staking, Token, Profile, Pleasureland.

**Roles:** Guest (browse marketing/token/staking read-only + public previews),
Fan (follow/subscribe/tip/comment/save + all AI), Creator (upload, tiers,
analytics, Co-Pilot), Admin (moderation, verification, health). Fans upgrade to
Creator via verification capturing identity, age verification, payout wallet.

## 3. The Five AI Cornerstones (all ship at MVP)

1. **Discovery Concierge (fans):** New users land in a short conversation that
   builds a personalized feed. Floating button to summon anytime. Claude Sonnet
   4, streaming, structured output, persistent preference vectors. System
   prompt versioned in `lib/ai/prompts/concierge.ts`.
2. **Creator Co-Pilot (creators):** Daily strategist — best posting times, 3
   caption variations (playful/intimate/bold), DM reply suggestions in the
   creator's voice, pricing recommendations, conversion analysis, weekly digest
   in plain language. Every recommendation has one-click apply.
3. **Smart Search (platform-wide):** Natural language → structured Supabase
   filters. Low-confidence fallback to Postgres `pg_trgm` full-text. Search
   history feeds relevance.
4. **Earnings Forecaster (creators):** Predicts next month's earnings with
   transparent breakdown + scenario sliders. Stat model in a Supabase Edge
   Function; Claude generates the narrative.
5. **Subscription Intelligence (fans):** Tracks subscriptions, notifies on
   posts, surfaces recommendations, reminds before auto-renew, summarizes what
   each creator posted since last visit. Supabase cron + Claude + Resend.

**Post-MVP AI (document only):** Mood Mode, AI Greeter, Trend Pulse, Caption
Translator, Visual Search.

## 4. Brand System

Keep the soul (pink, purple, magenta, diamond mark, playful confidence).
Target 2030 aesthetic: depth, motion, light, presence.

**Colors:** Deep Plum `#0F0420` (base), Imperial Purple `#2A0E5A` (secondary
surfaces), Electric Magenta `#FF1F8F` (primary/CTAs), Vivid Orchid `#B847FF`
(secondary accent), Soft Lilac `#E9D5FF` (text on dark), Aurora Cyan `#5DD6FF`
(interactive), Pure White `#FFFFFF` (headlines, sparingly).

**Gradients:** Primary CTA `linear-gradient(135deg,#FF1F8F→#B847FF)`; Hero text
`linear-gradient(90deg,#FF1F8F→#B847FF→#5DD6FF)`; Aurora bg animated radial
blend of magenta/orchid/cyan/imperial. Implement as CSS custom properties in
the design system package.

**Typography:** Display = Clash Display (Fontshare); Body = Inter; Mono =
JetBrains Mono. Variable fonts, preload critical weights.

**3D Icon System:** Every primary icon is a 3D extruded glyph — soft inner glow
matching section accent, gentle Y-axis rotation (±5°, 8s loop), magenta-tinted
depth shadow, glass edge highlights. MVP: ship PNG renders at 2x/3x in
`public/brand/icons/` as `{name}-2x.png` / `{name}-3x.png`; build
`<BrandIcon name="rocket" />` that picks density automatically. Until real
renders arrive, use stylized SVG placeholders labeled
`PLACEHOLDER_PENDING_3D_ASSETS`. Icons: Rocket (token), Heart (creators),
Diamond (NFT), Lock (staking), Globe (metaverse), Sparkle (AI), Crown (premium).

**Aurora Backgrounds:** Pure CSS radial-gradient + backdrop-filter. Four blurred
blobs drifting independently over 30-60s. Section tuning — Token: magenta+cyan;
Staking: purple+cyan; NFT: magenta+orchid; Creators: orchid+lilac. Build
`<AuroraBackground variant="token" />`. Disabled on `prefers-reduced-motion`.

**Glass-morphism:** Cards/modals/nav use `backdrop-filter: blur(20px)`,
semi-transparent fills, 1px hairline borders with magenta-tinted glow.

posts.caption, users.display_name, users.bio. RLS on every table; posts gated

**Auth (§5.4):** Email+password, Google OAuth, Wallet SIWE (server nonce → sign
→ verify → mint Supabase JWT). Wallet linkable to email; account merge

**Wallet (§5.5):** RainbowKit modal brand-styled. MetaMask, WalletConnect

switch on wrong chain. wagmi hooks throughout.

**Contracts (§5.6):** Do not deploy. $NSFW token
`0x8f006d1e1d9dc6c98996f50a4c810f17a47fbf19` (balance/transfer/approve).
Staking contract (PENDING). NFT contracts (PENDING). Typed ABIs in
`packages/contracts/`. Reads cache via React Query. Writes use wagmi

**AI (§5.7):** Every AI call through `/api/ai/*` route handlers (never

streaming, model `claude-sonnet-4-20250514`.
